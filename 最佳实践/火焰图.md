# 火焰图

通过火焰图可以直观地分析 CPU 性能瓶颈，找出热点函数。

## 完整流程

1. 编译程序
2. 运行 perf 采样
3. perf script 解析
4. FlameGraph 生成 SVG
5. 浏览器查看

## 1. 编译程序

编译时加上 `-g` 保留调试符号。

## 2. 安装 perf

```bash
sudo apt-get install linux-tools-common linux-tools-$(uname -r)
```

## 3. 采集性能数据

```bash
# -F 99: 每秒采样 99 次（避免与 100Hz 时钟中断同步造成偏差）
# -g: 记录完整调用栈
# -p: 指定目标进程 PID
# -- sleep 30: 采样持续 30 秒
sudo perf record -F 99 -g -p <PID> -- sleep 30
```

输出为当前目录下的二进制文件 `perf.data`。

## 4. 解析 perf.data

在 `perf.data` 所在目录执行，将二进制数据转为可读文本：

```bash
perf script > out.perf
```

> **注意：** perf.data 只能在生成它的机器上解析，ARM 设备生成的文件无法在 x86 PC 上使用（或许是可以）

## 5. 安装 FlameGraph

```bash
git clone https://github.com/brendangregg/FlameGraph.git
cd FlameGraph
```

## 6. 生成火焰图

```bash
# 折叠堆栈：合并相同的调用栈
./stackcollapse-perf.pl out.perf > out.folded

# 生成 SVG 火焰图
./flamegraph.pl out.folded > flamegraph.svg
```

## 7. 查看火焰图

用浏览器打开 `flamegraph.svg`，SVG 是交互式的：

- 点击某个色块可以下钻放大该函数的调用栈
- 鼠标悬停显示函数名和占用百分比

## 如何读懂火焰图

- **X 轴**：函数占用 CPU 时间的比例（越宽越耗时）
- **Y 轴**：调用栈深度（从下往上是调用关系）
- **颜色**：随机分配，无特殊含义
- **关注点**：找宽而平的色块，那就是性能瓶颈所在
